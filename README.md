# customer-segmentation-analysis
Análisis de segmentación de clientes: 197 000 clientes divididos en 6 segmentos sobre los que se pueden tomar medidas, utilizando la metodología RFM. Incluye un análisis global (Pareto) y una comparación normalizada por categorías. Impacto potencial en los ingresos: +16,4 millones de dólares.
